Leaderboard: why it still reads as a different site

Verdict: structure is right, the vocabulary is not shared Account →

The short answer

Round one judged this page on its own and found it sound. Next to Coins and Profile it is not the layout that differs, it is the parts: the header is the only one on the site whose h1 is not the page's name; the period control is a full-width three-segment bar where Profile uses underline tabs; the top-three ranks are filled ink discs, the one filled-ink element in the product; the score column is Manrope at a literal 1.05rem while every other figure on Coins is body type; rows are 56px where Coins rows are 44px; the "You" tag, the select, the offline box and the visually-hidden utility are all second recipes of things the shared CSS already has; and the loading state is a skeleton where the rest of the site uses the fin or a status line. Each of these is small. Together they are why it reads as a page from before the token pass. Every fix below is CSS or a component swap; the ranking, the data and the states stay.

What is right and stays

Canvas → one panel → rows. Rank as a number in text, never a medal colour. The viewer's row marked by a word and a 3px accent rule. Tabular numerals. The 30-day default. "Your place" pinned when the viewer is off the list. Offline shows the last board with its time. Nothing animates. Native <select> for the topic filter. Rows stack under 600px (useIsMobile), the avatar drops under 400px and the tab label shortens. Ranking, scope and data are untouched by every fix on this page.
