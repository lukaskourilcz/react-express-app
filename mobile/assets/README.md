# Mobile assets — PLACEHOLDERS

These PNGs are solid brand-green placeholders generated by
`scripts/gen-placeholder-assets.mjs` so the Expo config resolves and EAS builds
don't fail on missing icons. **Replace each with real artwork, keeping the exact
filenames and pixel sizes:**

| File | Size | Used for |
| --- | --- | --- |
| `icon.png` | 1024×1024 | iOS/Android app icon |
| `adaptive-icon.png` | 1024×1024 | Android adaptive foreground |
| `splash.png` | 1284×1284 | Launch splash |
| `favicon.png` | 48×48 | Expo web favicon |

Generate the real mascot with **Recraft** (SVG/app-icon output) or **Ideogram**
(text-in-image) — see the repo's `NEEDED.md` for the full asset checklist.
Regenerate placeholders anytime with `node scripts/gen-placeholder-assets.mjs`.
