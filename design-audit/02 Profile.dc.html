Verdict

Needs work, lightly. The information architecture is sound (identity → streak → career/paths/advisor · stats/garden/account) and the streak shield is a good, honest control. What makes it read as a game dashboard is decoration on numbers: six tinted tiles in five hues, icons that mean nothing (a bolt for "longest streak"), units in coloured pills, and a rotating motivational line. Strip those and the same cards look like an account page. Not verified in the live app — everything here is from source.

UX, states, mobile

Zero-data (new account). A first visit shows 0 · 0 streak tiles, "0 XP · Level 1 of 12", four 0 statistics, and the advisor's empty state: seven zeros before any content. Hide the Statistics card until the first quiz is recorded and let the streak card carry the one useful line ("Answer a quiz today to start a streak"). The shield control correctly renders nothing until the server confirms it.

Density / mobile. Eight cards stack in one column under 360px-per-column; Account deletion lands correctly last. With Statistics folded into Career (finding 5) it is seven; with Social removed (finding 6) six.

Navigation. The header shows no active state for /profile (it is reached from the avatar menu). Fine. The "Profile" kicker above the name is the only breadcrumb and duplicates the avatar menu label.

Dark theme (not verified). Astryx Card tints (orange, cyan, blue, purple) come from theme-neutral, not from the Deep End tokens, so their dark values were never tuned against #101c24. Neutral tiles (finding 5) remove the risk.

Accessibility. Good: roving tabs, labelled groups, 44px switches, streak values with aria-labels when unavailable. Watch the 0.72rem "2 protections left" meta line on the tinted tile: secondary text on an orange tint is below 4.5:1 in light mode by inspection of the tokens; verify.
