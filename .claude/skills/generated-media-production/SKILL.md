# Generated Media Production

Use this skill with `shark-product-context` and `deep-end-design-system`. Read `docs/design/generated-media-opportunity-audit.md`, `docs/design/generated-media-art-direction.md`, and `docs/design/generated-media-manifest.md` before generation.

## Gate the opportunity

1. Inspect Git state and the real target component, metadata path, current asset, crop behavior, bundle boundary, theme behavior, and responsive placement.
2. Classify the candidate as high-value, potentially useful, unnecessary, harmful, or inappropriate. Generate only when it solves a named product or communication problem.
3. Keep logos, functional icons, authentic UI, code, equations, factual maps, medical diagrams, meaningful chess positions, poker hands, charts, testimonials, users, and product data deterministic.
4. Define placement, aspect ratios, intrinsic dimensions, text-safe and crop-safe regions, light/dark behavior, mobile behavior, alt classification, performance budget, and static fallback before generation.

## Research and select a provider

1. Browse current official sources and compare at least three cheap or free generators before recommending or using one.
2. Verify pricing, commercial-use rights, privacy/data use, retention/training, account/card requirements, watermarks, export resolution/formats, aspect ratios, reference support, and website/API/MCP availability.
3. Record dated official sources in `docs/design/generated-media-opportunity-audit.md`; do not use affiliate roundups as authority.
4. Prefer a no-card free tier or low capped cost with clear commercial rights and clean original exports.
5. Never create an account, accept paid terms, purchase credits, change plans, enable auto-refill, expose credentials, or upload sensitive material without explicit owner authorization.
6. When the safest free option is website-only, provide exact prompts and filenames for owner generation, then inspect the uploaded originals.

## Generate and select

1. Write three genuinely different art-direction briefs, not three seeds of one composition.
2. Start from the prompt foundation in `docs/design/generated-media-art-direction.md`; include product-specific composition and a strict no-text/no-fake-UI/no-factual-artifact negative section.
3. Generate the three directions at economical review resolution using the owner-authorized workflow.
4. Inspect every result for generated text, watermarks, external logos, malformed objects, factual-looking errors, bad crops, weak negative space, AI clichés, and conflict with Deep End.
5. Reject weak directions explicitly. Refine the strongest direction, then produce required landscape, portrait, and square crops. Add motion only after the still system succeeds.

## Integrate production media

- Download only selected outputs. Keep discarded generations out of Git.
- Use AVIF or WebP for stills; use PNG only when transparency or tooling requires it. Include intrinsic dimensions and responsive sources.
- Add real EN/CS typography, code, equations, labels, product UI, and screenshots deterministically. Never ask a generator to reproduce them.
- Keep expressive media on public discovery and campaign surfaces. Do not load it in Quiz, Learn, Play, Profile, or `/dev` bundles.
- Give decorative media empty alt text. Give informative media concise localized alt text. Motion requires a poster and must freeze under reduced motion.
- Preserve product-aware metadata and environment URL registries; do not hard-code deployment URLs.

## Validate and record

Inspect the integrated result in StudyShark and devShark, EN/CS, light/dark, reduced motion, and relevant widths from 360 through 1440. Measure output bytes and verify lazy/preload behavior, crop stability, contrast behind deterministic text, and lack of layout shift.

Update `docs/design/generated-media-manifest.md` with the provider, model/version, dated official pricing/license/privacy sources, actual workflow, cost, complete prompt, negative prompt, references, job IDs when available, three reviewed directions, rejection reasons, selected variant, dimensions, crops, output paths, optimization, alt classification, fallback, provenance, restrictions, and regeneration steps. Never record credentials or claim a generation/check that did not succeed.
